# 按拦截判定

判定回答的是「这个域名拦了会不会出问题」，不是「它是不是广告」。大量统计、归因域名属于灰色地带，拦掉不报错但会丢数据。


| 判定 | 含义 |
| --- | --- |
| `拦截` | 直接拦截：无业务副作用，可整域封禁 |
| `拦截·代价` | 可拦，有代价：拦掉后丢失某项数据或功能，但不影响核心使用 |
| `部分` | 部分拦截：同域混用业务流量，只能按主机名或路径精确拦截 |
| `保留` | 不建议拦截：属业务基础能力，整域封禁会造成故障 |
